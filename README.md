# Campus Event Management System

## How to compile 
- Dowwnload all files excluding "Agile" and then create a java project called "CampusManagementSystem".
- Create the folderes "data", "service", and "ui" in the "src" folder.
- Add the "CampusEventApp" java file to the "Src" folder, this is what you run to start the application.
- Add "Event", "XMLDataStore" and "XMLUtils" to the "data" folder.
- Add "Event", "Feedback", "Role", "Room", and "User" to the "model" folder.
- Add "EventManager", "FeedbackManager", "NotificationService", "RoomManager", "UserManager", and "XMLDefaukts to the "service" folder.
- Add "AddUserDialog", "CreateEventDialog", "DashboardPanel", "EditUserDialog", "EventDetailsDialog", "EventListPanel", "FeedbackDialog", "LoginPanel", "MainFrame", "ManageUsersPanel", "RoomListPanel", and "UserListPanel" to the "ui" folder.
- Add "events.xml", "feedback.xml", "rooms.xml", and "users.xml" to the project root.
- Then run the application.
